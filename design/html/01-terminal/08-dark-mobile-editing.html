useEffect cleanup gotchas

react gotchas

The cleanup function does not only run on unmount. React runs it before every re-run of the effect.

  • Stale closures over state.
  • Async effects resolving after unmount.
JavaScript tap to edit 
useEffect(() => {
  const id = setInterval(tick, 1000)
  return () => clearInterval(id)
}, [delay])
