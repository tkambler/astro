useEffect cleanup gotchas

The cleanup function does not only run on unmount. React runs it before every re-run of the effect, so anything the effect opened gets closed on each dependency change.

  • Stale closure over state — the cleanup captures the value from its own render.
  • Async effects that resolve after unmount. Guard with an ignore flag.
  • Subscriptions keyed on an object literal, which is new every render.
1  useEffect(() => {
2    const id = setInterval(tick, 1000)
3    // runs before the next effect AND on unmount
4    return () => clearInterval(id)
5  }, [delay])

See also custom hooks I keep rewriting for the wrapper that fixes the third case.
